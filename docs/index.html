How the circuit is designed

Approved commitment

An issuer supplies one approved commitment in the contract constructor. Our prototype does not yet authenticate real-world issuers or verify off-chain completions.

Private witness, public nullifier

The Compact circuit takes a private secret, compares domain-separated commitments and inserts a one-time public nullifier after checking that it is unused.

Interactive educational model

This model is not the Compact contract or a ZK proof. It is a self-contained JavaScript explanation of the intended acceptance and replay flow. The actual generated Compact circuit is tested independently in the linked GitHub Actions run.
